# ♟️ Chess Move Prediction Using Deep Learning

A CNN-based Chess Move Prediction system built using TensorFlow/Keras.  
The model predicts the best next chess move from a given board position using Deep Learning.

---

## Features
- Chess move prediction
- CNN-based model
- PGN game parsing
- Board tensor encoding
- Legal move filtering

---

## Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- python-chess
